## Instructions for Running

### 1. Download the Project
Download or clone this repository from GitHub and open the project folder.

### 2. Open the Project Folder
Open PowerShell, Command Prompt, or a terminal and navigate to the folder containing m03-marquee-console.cpp.

For example, if the project is in your Downloads folder:
cd "C:\Users\YourName\Downloads"

Replace YourName with your Windows username.

You can check if the source file id in the folder by running:
dir

Make sure m03-marquee-console.cpp appears in the list.

### 3. Compile the Program
Make  sure a C++ compiler such as g++ is installed, then run:

g++ -std=c++17 m03-marquee-console.cpp -o m03-marquee-console

### 4. Run the Program
After compiling, run the program:

Windows:
.\m03-marquee-console.exe

Linux/macOS:
./m03-marquee-console

### 5. Use the Program
Once the program starts, type:

help

to display the available commands.
